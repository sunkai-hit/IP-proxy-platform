# IP代理管理平台 · V1.3 业务原型对照（历史V1.2工程持续复用）

当前演示原型继承V1.2/R3阶段的业务页面与交互，并依据V1.3需求进行对照收敛。原型使用模拟数据；正式后端和前端是独立工程，不能凭原型版本标识认定36项页面已验收。

## 本次原型升级重点

### 1. 视觉与布局对齐正式前端

原型不再使用“业务中心/运维中心”分组卡片式导航，而是参考正式前端 `ConsoleLayout.vue` 调整为：

- 左侧 236px 深色固定菜单
- 顶部白色控制台 Header
- V1.3 演示标识（仅静态模拟）
- Element Plus 风格的卡片、筛选栏、表格、Tag、弹窗
- 一级功能 + 二级菜单的控制台导航方式
- 资源、产品、订单与服务不再依赖页面顶部的大量 Tab 切换，而是从左侧菜单直接进入对应功能页

整体视觉基线与正式前端 `frontend/src/layouts/ConsoleLayout.vue`、`frontend/src/styles/index.css` 保持一致。

### 2. 资源模型收敛

自有资源主链统一为：

```text
CentOS → ROS → 家宽/线路（节点）→ 当前公网IP
```

- 原“主机列表”对应新平台 CentOS 列表。
- 原“ROS主机”对应新平台 ROS 列表。
- 原“ROS逻辑线路”和“节点列表”统一建模为“家宽/线路”。
- 当前IP作为家宽/线路的运行属性，不再单独建设IP资源列表。
- 资源池是对多个家宽/线路的逻辑组织，不等同于旧系统节点。
- BAS/BRAS/PPPoE Server 信息在线路层记录，并在 ROS 层汇总。

### 3. CentOS、ROS与线路运行信息

- CentOS保留其运行指标及B/C段聚合统计；B段/C段不作为ROS运营指标。
- ROS保留CPU、内存、硬盘、系统负载和线路/拨号统计，可查看其关联线路、BAS及上报时间。
- 不设计ROS自动主备或自动切换；长效服务如涉及固定出口切换，须单独进行人工预检、授权和产品组真实验证。

### 4. 外部资源交付模式调整

外部供应商资源不再默认进入自有资源池，而是按真实业务形成独立链路：

```text
外部供应商 → 运营采购套餐 → 反向代理配置 → 平台代理入口 → 客户服务实例
```

原型增加：

- 外部供应商
- 外部套餐/资源采购
- 反向代理交付

### 5. 产品管理简化

产品资源选择、切换、调度等规则由开发人员在代码层实现，不再提供“产品资源策略”业务配置页面。

产品管理保留：

- 产品列表
- 短效IP
- 长效IP
- 独享IP
- VPN
- 隧道
- 套餐管理

### 6. 服务交付区分

服务实例增加交付方式：

- `SELF_OWNED`：自有资源交付
- `EXTERNAL_PROXY`：外部供应商套餐通过反向代理交付

### 7. 监控中心收敛

监控中心仅保留：

1. CentOS监控
2. ROS监控

家宽/线路的拨号、当前IP、延迟、VPN重拨等仍在线路列表和日志中心查看，不再单独建设监控中心页面。

### 8. 告警重构为“长效代理监控”

原通用基础设施告警规则页面调整为客户长效代理专项监控：

```text
客户 + 长效服务 + 代理目标
        ↓
      定时检测
        ↓
      代理异常
        ↓
客户钉钉/飞书机器人
```

原型包括：

- 长效监控配置
- 客户机器人配置
- 告警记录
- 通知记录
- 恢复记录

机器人支持钉钉、飞书，Webhook/API、Token/Key、Secret等敏感信息均按脱敏展示设计。

## 当前页面范围

- 首页工作台
- 客户管理：客户列表、客户认证、客户账号
- 资源管理：资源概览、CentOS、ROS、家宽/线路、资源池、独享资源、域名配置、外部供应商、外部套餐/采购、反向代理交付
- 产品管理：产品列表、短效IP、长效IP、独享IP、VPN、隧道、套餐管理
- 订单与服务：订单管理、服务开通、服务实例、服务变更、到期与资源释放
- 监控中心：CentOS监控、ROS监控
- 运行日志：IP提取、使用、API、ROS运行、线路拨号、IP变化、远程操作、域名变更、外部代理、操作日志
- 长效代理监控：监控配置、客户机器人、告警记录、通知记录、恢复记录
- 数据统计：基础资源、客户使用、产品与服务、外部资源交付
- 系统管理：用户、角色、字典、参数、登录日志、操作审计

## 运行

无需构建依赖，直接打开 `index.html`，或：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

> 当前为需求与交互验证原型。数据全部为模拟数据，搜索、新增、编辑、同步、监控采集等操作不会修改真实业务数据。

- `index.html`：V1.3 业务模拟原型入口（沿用既有静态脚本）
- `styles.css`：按正式前端视觉重新整理的静态样式

- `v12-app.js`：V1.2 页面与交互逻辑
- `v12-console-ui2.js`：参考正式前端实现的控制台布局、二级导航和页面路由适配
- `app.js`：V1.0 历史原型脚本，保留用于版本对照，当前入口不再加载
