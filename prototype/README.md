# IP代理管理平台 · V1.2 原型演示

当前原型已基于《IP代理管理平台需求说明书（详细需求版 V1.2）》完成业务模型升级，继续沿用原有后台视觉风格与纯前端交互方式。

## V1.2 核心变化

### 1. 资源模型收敛

自有资源主链统一为：

```text
CentOS → ROS → 家宽/线路（节点）→ 当前公网IP
```

- 原“主机列表”对应新平台 CentOS 列表。
- 原“ROS主机”对应新平台 ROS 列表。
- 原“ROS逻辑线路”和“节点列表”统一建模为“家宽/线路”。
- 当前IP作为家宽/线路的运行属性，不再单独建设IP资源列表。
- 资源池是对多个家宽/线路的逻辑组织，不等同于旧系统节点。
- BAS/BRAS/PPPoE Server 信息在线路层记录，并在 ROS 层汇总。

### 2. ROS增强

ROS列表和监控增加：

- CPU、内存、硬盘、系统负载
- 线路总数、在线线路数
- 当前拨号IP数量
- B段数量：按IPv4 `/16` 前缀去重
- C段数量：按IPv4 `/24` 前缀去重
- BAS数量/汇总
- 主备、替换、自动切换、上报时间

### 3. 外部资源交付模式调整

外部供应商资源不再默认进入自有资源池，而是按真实业务形成独立链路：

```text
外部供应商 → 运营采购套餐 → 反向代理配置 → 平台代理入口 → 客户服务实例
```

原型增加：

- 外部供应商
- 外部套餐/资源采购
- 反向代理交付

### 4. 产品管理简化

产品资源选择、切换、调度等规则由开发人员在代码层实现，不再提供“产品资源策略”业务配置页面。

产品管理保留：

- 五类产品：短效IP、长效IP、独享IP、VPN、隧道
- 套餐管理

### 5. 服务交付区分

服务实例增加交付方式：

- `SELF_OWNED`：自有资源交付
- `EXTERNAL_PROXY`：外部供应商套餐通过反向代理交付

### 6. 监控中心收敛

监控中心仅保留：

1. CentOS监控
2. ROS监控

家宽/线路的拨号、当前IP、延迟、VPN重拨等仍在线路列表和日志中心查看，不再单独建设监控中心页面。

### 7. 告警重构为“长效代理监控”

原通用基础设施告警规则页面调整为客户长效代理专项监控：

```text
客户 + 长效服务 + 代理目标
        ↓
      定时检测
        ↓
      代理异常
        ↓
客户钉钉/飞书机器人
```

原型包括：

- 长效监控配置
- 客户机器人配置
- 告警记录
- 通知记录
- 恢复记录

机器人支持钉钉、飞书，Webhook/API、Token/Key、Secret等敏感信息均按脱敏展示设计。

## 当前页面范围

- 首页工作台
- 客户管理：客户列表、认证审批
- 资源管理：资源概览、CentOS、ROS、家宽/线路、资源池、独享资源、域名配置、外部供应商、外部套餐/采购、反向代理交付
- 产品管理：产品列表、套餐管理
- 订单与服务：订单管理、服务开通、服务实例、服务变更、到期与资源释放
- 监控中心：CentOS监控、ROS监控
- 日志中心：IP提取、使用、API、ROS运行、线路拨号、IP变化、远程操作、域名变更、外部代理、操作日志
- 长效代理监控：监控配置、客户机器人、告警记录、通知记录、恢复记录
- 数据统计：基础资源、客户使用、产品与服务、外部资源交付
- 系统管理：用户、角色、字典、参数、登录日志、操作审计

## 运行

无需构建依赖，直接打开 `index.html`，或：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

> 当前为需求与交互验证原型。数据全部为模拟数据，搜索、新增、编辑、同步、监控采集等操作不会修改真实业务数据。
