## 本轮跨页面及敏感子表收敛（2026-10-15）

**实际代码修复：**

- `SupplierPurchaseView`：连续登记供应商采购时彻底重置采购生效/截止、成本/额度与客户归属；客户发生变更时拒绝过期的异步已付款订单查询结果；保存前确保来源订单仍属于当前显示的有效付款候选。
- `ReverseProxyView`：切换关联供应商采购时，禁止上一个客户异步返回的服务列表覆盖新客户；保存前重新核对采购客户和可选服务所属关系。产品组真实网关未接，不会因此显示实际可用。
- `ServiceChangeView`：切换原服务、操作类型或续费订单时，禁止延迟返回的旧订单/期限快照覆盖当前选定服务；原到期锚点与后端付款/归属/去重守卫保持不变。
- `CustomerController.customer`：`customer:read`仅返回基本客户及允许读取的概况；认证材料`authRecords`须`customer:auth:read`、客户账号`accounts`须`customer:account:read`、服务关联`services`须`service:read`。直接`customers/{id}/services`也要求客户+服务双权限，避免只隐藏Vue页签时信息仍通过HTTP泄露；`CustomerDetailView`对应页签和导航同步按权限显示。
- `OrderServiceController.detail`：凭证、变更历史、释放记录、长效专项监控按照各自独立读取权限从业务HTTP响应中剔除；`V12ServiceMapper.bindings`不再给通用详情返回未经限定的资源绑定`metadata`；`ServiceDetailView`相应页签同步权限。
- `prototype/README.md`更正仍遗留的“ROS显示B/C段和自动主备”错误旧叙述：B/C段仅为CentOS归集统计，长效出口仅允许人工切换/产品组真实核验；原型仍为Mock。
- `scripts/ci_v13_ui_workflow_gate.py`统一核对核心路由、跨页面客户/订单/服务/资源关联入口、异步旧响应防串单守卫及页面/后端RBAC对应；与Java权限回归、Vue构建、PostgreSQL/HTTP合成业务测试共同作为离线验收证据。

**证据边界：** 自动化静态源代码核查不代表浏览器逐按钮点验；用户角色组合的真实交互与产品组实网释放/转换仍需另行完成。现有Flyway V1–V27未修改，也未加入新商业功能。
