## 外部技术待签收

1. 真实停服和访问阻断：五款产品与资源API应提供产品操作的稳定幂等键、查单、网络拒绝连接证据和采样时间。当前 Planner 仅保存任务，不调用这两个团队的执行接口。
2. 宽限释放：产品下线、平台代理解绑、资源侧解绑/公网IPv4真正可售必须分别验证；缺一项不能解除 svc_egress_claim。
3. 外部代理采购到期：C03已批准到期停服，但真实反向代理执行尚未签约，本轮不能把到期查询/任务登记伪称真实网关关闭。
4. 续费：自有产品需签署真实续期/恢复，外部采购需人工先确认客户已付款再续购供应商并验证新采购覆盖期/反向代理状态。
5. 存量数据库：V24的旧占用保守拦截意味着遗留固定IP缺快照时不能直接对外执行变更；先完成Issue #5的只读核对和审计迁移。

## 工程验证门槛
- 运行 PostgreSQL+Flyway 全量迁移，CI用**纯合成**0天/3天长效服务记录检查：首次扫描创建动作、重复扫描不创建第二份、业务状态仍ACTIVE、没有已释放出口。
- Mock服务暂停/续费不能更新业务期限；真实网络验证由 E2E 矩阵另外签收。
- 客户已付款续费订单的专属绑定与同客户、套餐快照须经HTTP负面用例再验证；已移除曾因格式错误 JSON 导致HTTP 500而误通过的无效CI断言，不能计算成业务负测通过。
- 仅当CI在**精确最终提交SHA**成功时，标记工程门槛通过。所有真实E2E仍显示未运行。
