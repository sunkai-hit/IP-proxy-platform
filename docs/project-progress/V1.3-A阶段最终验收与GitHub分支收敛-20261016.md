- **临时清理分支**：`chore/v13-a-acceptance-branch-prune-20261016` 也仅用于此 PR，已单独加入自动化白名单；合入 main 后只有通过祖先与 lease 验证才删除。
- **结束后**：核对 GitHub Actions 删除日志、剩余分支、archive tag，然后移除一次性清理 workflow；避免留长期写权限工作流。若 workflow 令牌缺少写权限，以实际失败为准，不能宣称已删除。
