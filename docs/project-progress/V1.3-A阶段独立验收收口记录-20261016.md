## 8. 第四轮 A2/A5 释放回查、通知筛选及告警归档（验收以当前 PR CI 为准）

本批仅修正独立管理平台现有页面和 UI 交互，不更改跨组契约或实际代理执行逻辑：

- **A2 到期/资源释放任务**：任务抽屉从队列切换时，以 `operationKey` + 请求版本校验详情结果，延迟返回不能覆盖其他任务或已关闭抽屉；详情读取失败或身份不符有页面错误及重试，不得被解释为停服或回收成功。
- **A2 释放预检**：结果与当前任务绑定，任务切换立即清除旧预检；预检失败显示“宽限、共享占用及回执条件未知”并提供独立重试。这里显示的是平台业务预检，不等于真实公网 IP 释放。
- **A5 告警归档**：二次确认与原因输入采用单次操作锁，确认期间切换告警或状态发生变化不提交旧操作，取消不会请求归档接口；人工归档状态与真实代理网络恢复仍分离。
- **A5 通知记录**：同一个通知页面上，告警跨客户/监控路由查询改变时重新读取对应通知及页码；“查看全部通知”切回无筛选结果，不沿用之前告警数据。
- **回归**：新增四项 Chromium 页面案例（任务详情及预检失败重试、慢响应跨任务隔离、同页通知筛选刷新、归档取消不发写请求），同一 CI 对原有业务页面做全量回归。完成标准为最终提交、合并后的主分支分别全绿；自动化绿灯不等于 36 页面人工逐项签收。
