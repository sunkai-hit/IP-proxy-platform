## 第一版集中验收操作顺序

对每条业务链统一执行这六项，不再单独开新设计工作：

1. **列表**：按编号/名称/状态/客户筛选并恢复，关注无数据、无权限、分页。
2. **详情**：主记录和当前业务状态正确，真实采样有来源和时间，敏感凭证不可回显。
3. **子表**：订单项与服务实例、线路与池成员、采购与代理、监控与通知的主子归属一致，不以裸ID/原始JSON代替业务。
4. **关联跳转**：从业务对象发起合法新建、预选当前客户与原服务，返回时上下文不丢失。
5. **合法/非法操作**：强制付款先行；0宽限明确确认；人工切换、停服、回收未真实验证时不得假成功；确认原因与权限一致。
6. **结果回查**：操作后直接进入已产生单据详情，失败不丢原服务期限、客户固定出口与已有绑定；异步任务/回执按真实来源查看。
