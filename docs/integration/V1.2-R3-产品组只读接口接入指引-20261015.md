# V1.2-R3 第五批｜产品组实时只读接口接入指引

> **工程交付，不改变已确认的业务需求。** 本批建立真实HTTP读取通路，不等同于产品组已部署、两组已完成联调，更不自动启用远程写操作。对照《IP代理管理平台与代理产品服务接口设计规范 V1.0》（两组联合评审稿）的既有候选路径。

## 配置

- `PRODUCT_GROUP_BASE_URL`：产品组HTTPS服务根地址，如 `https://proxy-api.example.invalid`，不得带路径、查询、认证信息。仅本机开发允许 `http://localhost` 或 `http://127.0.0.1`。
- `PRODUCT_GROUP_API_TOKEN`：**业务平台出站调用产品组**的专用Bearer密钥，至少32字符，严禁记录、写入版本库或展示给前端。
- 任一为空、无效或不符合URL约束，所有读取接口返回 `PRODUCT_INTEGRATION_NOT_CONFIGURED`；管理页面只能显示“尚未接通”，不可退回旧缓存装作实时资源。
- 与上批 `PRODUCT_INTEGRATION_BEARER_TOKEN`（**产品组入站调用业务平台**的授权预检密钥）分开保管与轮换。

## 双组只读映射

| 业务平台管理员接口（受原有权限约束） | 对应产品组候选HTTP GET | 必要说明 |
|---|---|---|
| `/api/admin/v1/v12/product-integration/status` | 不发远端请求 | 配置状态；不等于设备在线 |
| `.../capabilities` | `/product/v1/capabilities` | 五款产品支持能力，检查有效`productTypes/sampledAt` |
| `.../short-pool` | `/product/v1/short-pool` | 保留在池内的短效资源、用户使用数与连接数分别展示 |
| `.../long-pool` | `/product/v1/long-pool` | 查看已转为长效的共享候选、剩余共享容量 |
| `.../services/{serviceId}/actual-status` | `/product/v1/services/{serviceId}` | 实际运行状态与产品组核验状态只读 |
| `.../tasks/{operationId}` | `/product/v1/tasks/{operationId}` | `ACCEPTED/PENDING/UNKNOWN`均不是完成 |

管理端 `resource:read` 可读能力和资源池，`service:read` 可读实际服务和任务。响应字段白名单防止产品侧意外字段（例如凭证）被透传。客户端请求连接超时2秒、总请求超时5秒、不跟随重定向；远端非200、格式不合规、JSON过大及异常一律失败关闭。

## 不可越过的安全边界

1. **快照不是资源预占**：即使产品组回复在线、当前用户数、长效剩余容量，业务平台也不得直接据此认定已原子占用成功。
2. **任务成功不等于服务验证**：执行 `SUCCEEDED` 必须继续核对代理真实状态、外网出口、协议及授权；仅读取结果不改变 `svc_instance`、`svc_egress_claim`。
3. **读通不等于开通通**：本批不发 `/product/v1/services/provision`、转换、释放、续费和授权撤销写请求；原有 `Noop` 默认拒绝保持。
4. **权限由业务平台决定**：只读状态不修改订单、客户权益和资源提取配额；产品组返回的缓存数据不替代业务平台授权判断。
5. **存量兼容**：原V1～V27迁移不修改；旧业务接口继续按前四批已批准的保护规则运行。

## 双组联调最低签收点

- 产品组提供测试地址、测试密钥和上述GET响应样例，使用稳定的resourceId/lineId/serviceId/operationId；
- 短效池至少提供`activeUserCount`、`activeConnectionCount`、`mode`、`sampledAt`；长效池提供真实`shareSlotsRemaining`和容量依据；
- 验证真实200响应、超时、非200、格式错误、时间戳变化与RBAC拒绝；同一公网IPv4不能在短效/长效/独享被错误重复展示为可交付；
- 此后再讨论**持久化异步操作任务→远端幂等执行→查单→真实网络验收→业务服务状态提交**，不能从数据库事务中直接发出不可补偿的远端写命令。

## 验收证据

回归测试：`ProductGroupReadClientTest`、`ProductGroupReadControllerTest`；CI在产品组地址空白时验证管理端状态为`configured=false`、短效池查询失败关闭，全部真实网络侧验证须产品组环境联调后再签收。
