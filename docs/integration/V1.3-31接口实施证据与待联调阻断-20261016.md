# V1.3｜31 项跨组接口的源码实现证据与联调阻断清单

> 核对日期：2026-10-16；核对对象：`main` 的产品组读桥、候选停服/释放写桥、业务平台授权控制器、旧短效 Open API 及 `docs/integration/V1.3-31接口联合技术签收矩阵-20261016.md`。本表是**业务平台仓库源码能力映射**，不表示产品组或资源 API 组的代码已经交付、真实环境已可用或接口完成签收。

## 只读样本时效和容量完整性门槛（2026-10-16，管理平台工程守卫）

业务平台消费产品组候选 A01/A04/A05/C02 时，**不仅校验 `sampledAt` 格式，还要求顶层及资源项采样均在最近 15 分钟内且不超过当前时间 2 分钟未来偏差**。过期、未来时钟偏差会拒绝作为当前真实资源或运行状态使用，返回 `PRODUCT_INTEGRATION_STALE_SAMPLE`。该 15 分钟与 2 分钟数值是本仓库的**保守工程默认值**，不是产品组已签署的合同 SLA；联调时应根据真实采样频率及三方时钟同步要求协商，未协商前不得靠管理缓存无限延长样本生命。

资源池对资源 ID 去重，使用人数、连接数、总容量、共享剩余槽位必须为可表示的非负整数，`convertible` 必须为布尔；能力声明的可用标志必须为布尔，类型不得重复；远端任务返回 `accepted=false` 与 `status=SUCCEEDED` 同时出现时视作矛盾而拒绝。**即使这些本地校验通过，产品组读桥也只属于咨询性观察，不构成预占、独享资源锁、客户额度扣减、停服或真实代理出口验收**。后续必须保留时间新鲜度和独享 claim 验真的双重约束。

## 跨组释放回执与原指令强绑定（2026-10-16，业务平台候选闭环）

产品组 RELEASE 查单 `status=SUCCEEDED`、实际服务 `STOPPED/VERIFIED` **不足以**允许标记“待业务提交”。任务对账必须从本地持久化 `svc_action_task.request_summary` 读取最初的 `releaseMode` 和 `egressIpv4`，与远端 `releaseVerification` 逐字段一致，并检查 `serviceAccessRevoked=true`、合法核验时间；最后一个共享客户回短效还需要 `allOldAccessRevoked`、`switchedToShort`、`shortPoolHealthy`、非空 `resourceId`。同时要求实际服务核验 `verifiedAt`、`sampledAt` 一致、不来自未来、不过期。任何不符均停留在 `VERIFYING/WAITING_NETWORK_VERIFICATION`，业务服务和公网 IPv4 占用均不得更新。即便候选查单验证通过，最终 `ProductGraceReleaseCommitter` 仍按合同宽限、原 IPv4、其他有效占用及历史独享快照再做数据库事务核验。

候选写适配 `ProductGroupStopClient` 对 RELEASE IPv4 逐段校验，对到期停服 `effectiveAt` 严格要求有效时区时间；输入无效时不得请求外部网络。**这些安全门槛不是产品组真实任务执行证据，也不代表三方已签署完整接口。**

## 一、已可定位的工程实现与缺口

| 候选编号 | 业务平台源码位置 | 本仓库可核对的实际行为 | 当前验收结论 |
|---|---|---|---|
| A01 | `ProductGroupReadClient.capabilities`、`ProductGroupReadController.capabilities` | 对 `GET /product/v1/capabilities` 的**消费方**只读 HTTP 桥接；响应必须含产品类型数组和采样时间；缺 URL/Token 拒绝 | 已有消费方校验，**无产品组真实响应签收** |
| A04 / A05 | `ProductGroupReadClient.shortPool/longPool` | 读取 `/product/v1/short-pool`、`/product/v1/long-pool`；校验资源 ID、线路 ID、模式、健康与采样时间，标记 `advisoryOnly=true`；**不是容量锁** | 已有只读桥，不得据此分配/转换 |
| C02 | `ProductGroupReadClient.actualService` | 读取服务实际状态与验证状态，校验枚举、服务 ID 和 `sampledAt`；`VERIFIED` 仍需管理面独立核查 | 消费方校验存在，缺真实网络回执 |
| C03 | `ProductGroupStopClient.pauseForExpiry/releaseAfterGrace` | 仅部分 `POST /product/v1/services/{serviceId}/actions` 候选动作；必须显式开启产品组写开关、匹配 `operationId` 与受理回执；`HTTP 202` 不代表已停服或 IPv4 释放 | **部分适配器，不等于完整暂停/恢复/续费/终止签收** |
| C07 | `ProductGroupReadClient.taskStatus` | `GET /product/v1/tasks/{operationId}` 只读查询远程操作结果，校验 ID、状态及受理字段 | 已有消费方适配，仍需远端真实任务样本 |
| D01 | `ProductAuthorizationController.check`、`ProductAuthorizationService.check` | 业务平台提供 `POST /business/v1/authorizations/check`；专用 Bearer 凭证鉴权；仅 `SHORT_EXTRACT` 非扣额权限预检，其它动作默认拒绝；5 秒以内短 TTL | **部分实现：未原子扣额、未分发真实短效 IP** |
| F04（旧路由风险） | `OpenApiService.extract` | 旧 `/api/open/v1/proxy/extract` 读取管理快照，已默认阻断；只可在显式开启 `LEGACY_SHORT_EXTRACT_ENABLED` 且 `m6-mock` 中执行合成演练 | **没有替代产品组 F04 真实交付** |

上述行为中的候选 URI、字段边界、授权动作以当前实现源代码为准；**候选合同路径和实际管理端 API 前缀不同**，不能把管理端代理页面上的 REST 地址登记为产品组端点的实现证据。

## 二、未在上述桥接层形成真实执行证据的接口组

| 候选编号 | 必须由提供方出具的最小联调证据 | 收敛状态 |

| A02 / A03 / A06 | 三组确认的 CentOS/ROS/线路/资源稳定 ID、当前拨号 IPv4 与固定出口的区分及去重样本 | 待资源 API 组、产品组联调 |
| B01–B05 | 原子预占/锁单位、TTL、长效共享容量、短效迁移、独享唯一性、失败补偿及并发冲突演练 | **P0 真资源交付阻断** |
| C01、C04–C06 | 五款代理真实开通、最后占用回短效、人工主备预检/切换、共享客户不误伤及成功回执 | 待产品组实网任务 |
| D02、D03 | 真实凭证存活性查询、撤销传播 TTL、断链拒绝、跨租户与重复请求验证 | 待双方鉴权签收 |
| E01–E04 | 产品组真实资源事件和使用量样本、去重/对账结果、源时间、单位及差错回放 | 待真实事件/账本联调 |
| F01–F03、F05–F06 | 线路变化、DNS/反向代理真实执行、设备操作和代理日志/探测样本 | 待产品组与资源 API 组确认 |

“未形成证据”是**本仓库目前的交付边界**，不代表有证据证明外部团队尚未开发。只有外部实际 API、网络回执、操作编号及双方/三方签字才能改变原 31 项矩阵中的签收状态。

## 三、当前最短闭环路径

1. **先做只读与身份一致性**：A01/A02/A03/A04/A05/A06、C02、C07；确认 `sourceId`、`serviceId`、`sampledAt` 与 HTTP 错误代码真实样本，不先开启产品组写开关。
2. **再做安全资源写闭环**：B01–B05 → C01/C03/C04 → F04；提供相同 `operationId` 的预占、转换、失败回滚、实际公网出口核验和重复请求/超时查单证据；特别验证已有短效使用者迁移与独享 IPv4 跨服务不可复卖。
3. **最后做真实数据对账**：D01–D03 的用量权益扣减、E01–E04 数据回传与 F 系列运维；每类实际服务给出至少一次有效流量、停服、续费/宽限、释放回池的产品组回执。
4. **两个发布门槛独立**：管理面 Playwright/PostgreSQL CI 全绿仅可说明业务平台工程回归通过；**31 接口签收和 18 项真实网络 E2E 未完成时不得宣布 V1.3 实际代理产品可上线**。
