## 二、双方必须核实的契约字段

每项签收均需形成版本化接口合同：**唯一资源/业务标识、调用方/提供方、业务鉴权、请求字段及必填/类型、响应字段及单位、错误码、幂等 operationId、真实状态与 sampledAt、超时查单与补偿策略、频率/容量限制、脱敏日志和允许执行环境**。不同端点按适用性填写，不凭页面字段猜测真实设备能力。

| 验收域 | 最低签收证据 | 当前结论 |
|---|---|---|
| A01–A06 资源/容量查询 | CentOS/ROS/线路稳定来源 ID；当前 IPv4 与合同固定出口区分；短效 IP 使用人数/连接数、长效剩余共享容量、采样时刻 | 现有平台读桥仅支持离线/候选契约校验，尚无产品真实样本 |
| B01–B05 原子分配与转换 | 预占 TTL、资源/出口锁单位、短效用户迁移、转换成功后的端口隔离与实际出口、异常回滚、并发冲突 | 无真实产品转换/回滚回执 |
| C01–C07 真实服务生命周期 | 开通/停服/续费/释放/切换任务、`operationId` 查单、`SUCCEEDED` + 网络验真、共享客户不误回池 | 管理面异步任务和提交守卫已有，产品组环境未签收 |
| D01–D03 统一权益/授权 | 业务平台唯一决策、身份真实性、额度扣减原子性、授权 TTL、撤销传播、断链拒绝策略 | `SHORT_EXTRACT` 非扣额预检有实现，不代表实际资源分发 |
| E01–E04 数据反馈与对账 | 资源变更事件、真实流量/使用量、样本时间、重复上报去重、业务/产品账本差异清单 | 需产品组上报实际样本 |
| F01–F06 补充能力 | 线路事件、DNS、反代、实际短效提取、受控设备动作、真实日志和长效专项探测；按能力声明开放 | 本组为已编写的候选接口，尚未统一签署 |

## 三、三组实施边界（不重新定义产品责任）

- **业务平台组**：客户、订单、付款核实、合同权益、所有客户使用授权的权威决策；独立维护管理界面、数据库账本、审计、任务与结果回查。
- **代理产品组**：Proxy/VPN/隧道真实连接、出网、分配和转换、短效用户迁移、实际停复服与安全回池、真实流量及执行回执。
- **资源 API 组**：CentOS/ROS/线路等稳定身份和设备/拨号的实际控制与观测数据。候选 URI 中 `/product/` 仅表示当前跨组交互入口命名，**不能据此判定资源 API 组的独立服务已被产品组实现**；本表“资源侧协作”是待签收建议边界。

## 四、联调和状态关闭准则

1. **接口冻结**：两组逐项确认最终 URI/Method/请求与响应参数、错误码、真实调用责任、例子及变更兼容策略；三组之间的资源接口转接责任须书面确定。
2. **功能联调**：按「只读资源与授权 → 原子预占/长效复用与迁移转换 → 真实停服/释放回池 → VPN/隧道和观测统计」执行。每项必须包含权限拒绝、并发、超时查单、重复请求、失败回滚的适用用例。
3. **真实签收**：用脱敏的 `operationId`、回执、实际网络验证结果、`sampledAt`、业务归属和责任组签字证明；`HTTP 202` 或 Mock 不算真实成功。
4. **安全开关**：真实写入功能在签收完成前继续默认关闭，平台状态、任务状态、网络状态必须分开；无网络证据不能解除出口占用。
