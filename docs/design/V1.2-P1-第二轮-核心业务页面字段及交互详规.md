## 1. UI-19｜套餐管理：宽限期与资源承诺（P0）

**菜单路径**：产品管理→套餐管理；由产品详情的“套餐”子表亦可进入。

### 1.1 列表与详情字段

| 层级 | 字段/元素 | 业务行为 |
|---|---|---|
| 筛选 | 套餐编号/名称、所属产品、五类产品类型、上架状态 | 现有字段；支持组合筛选 |
| 列表 | 套餐编号/名称、产品、服务周期+单位、IP/资源数量、价格/币种、状态、**宽限天数**、使用中服务数 | 宽限仅适用明确配置的长效、独享；其他产品显示“不适用/按专项规则”，非无条件宽限 |
| 顶部摘要 | 产品类型、认证方式、可售省市/运营商、资源模式/固定IP要求、系统内置规则版本 | 产品信息只读，点击可跳产品详情 |
| 权益子表 | IP数/去重IP计数口径、提取次数、流量Byte、并发、设备、白名单、可更换次数 | 精确单位、非负/正数校验，按产品类型显示相关项 |
| 使用中服务子表 | 服务号、客户、业务生效/到期、宽限结束、固定出口IP、服务状态 | 查看正在使用此套餐的服务，服务快照不自动被新套餐规则覆盖 |
| 变更历史 | 操作人、字段变更前后、影响分析、操作原因、时间 | 价格和宽限期调整留痕 |

### 1.2 编辑与操作

- **[确认]** 长效套餐与独享套餐各自可编辑“续费宽限天数”，**不采用系统统一固定天数**。
- **[建议]** 输入为非负整数“天”，显示“业务到期后立即停服，最多保留固定出口至：服务到期时刻＋本套餐宽限天数”。填写0表示不启用宽限的边界是否允许销售需业务确认，**不擅自给默认天数**。
- **[建议]** 保存前校验“宽限=天数”与“套餐有效期=天数”分开；宽限不是延长可使用时长。创建服务时固化宽限与固定IP承诺到服务快照。
- **[建议]** 修改已有销售套餐时展示“已有服务数及是否追溯”说明，默认只影响未来新服务；现有服务需走受控服务变更，不直接被套餐改动覆盖。
- **[建议]** 产品页保留独享数量、长效更换规则，但产品专项配置中“故障自动替换”之类旧控件不得与**只做人工主备切换**冲突：在本轮方案中隐藏未批准的自动切换入口并提示属代码策略/待确认，不删除历史字段。
- **[待接口]** 产品组是否能保证原公网IPv4在服务期限及宽限期持续可保留，需在可售能力校验中显式展示；不能只靠前端勾选“固定IP”。

**验收**：不同长效/独享套餐可以配置不同宽限天数；服务快照保留开通时的宽限；历史套餐编辑不静默改已有服务；宽限开始后客户不能继续使用。

## 2. UI-11｜独享出口占用：从线路锁定转为对外IPv4跨客户排他（P0）

**菜单路径**：资源管理→独享资源；同时作为服务详情→资源绑定下的子表。

### 2.1 列表字段和筛选

| 区域 | 字段 | 展示/规则 |
|---|---|---|
| 查询 | 固定出口IPv4、线路编号/别名、服务号/客户名、占用模式、状态、到期区间、ROS/地区/运营商 | 客户只作为**服务绑定派生查询**，线路主表无客户属性 |
| 主列表 | 出口IPv4（合同交付快照）、当前上报IPv4、源线路、ROS、占用模式共享/排他、所属服务、客户、占用开始/预期结束/宽限保留截止、健康状态、交付验证时间 | IP变化分列，不能用当前IP自动覆盖固定IP承诺 |
| 分组/汇总 | 有效独享出口数、跨客户冲突数、宽限保留数、待回收数、无能力证明数 | 多线路同IP去重；多池重叠不得重复统计 |
| 详情子表 | 出口引用的服务列表、线路/拨号历史、相关域名/平台代理入口、变更/故障切换与回收日志 | 可从服务/线路两头定位，不新增customer_id到线路 |

### 2.2 业务操作、保护与反馈

- **[确认]** 独享跨客户排他单位为**公网出口IPv4**，即使端口不同、来自不同线路或不同池也不放行他客共享；长效可在非独享条件下多客户共享。
- **[建议]** “分配/更换/释放”均从具体服务或受控资源操作入口进入；显示来源、IP授权方式、占用客户、有效服务/暂停/宽限引用、冲突证据。
- **[建议]** 新分配前做全局冲突查询：按IPv4汇总所有ACTIVE/暂停/宽限保留/切换预占；若同IP有其他客户共享长效或独享，拒绝新独享；若同IP已有其他客户独享，拒绝任何他客长效/独享。
- **[建议]** 服务按套餐要求N个独享IP时，以**去重IPv4**核算权益，不以N条线路/端口凑数。相同客户多服务复用策略仍需确定，默认同IP不计两个独享名额。
- **[建议]** “释放”需二次确认；宽限内禁用普通释放（或进入有影响评估的强制终止流程），执行远端关闭及释放成功后才撤销排他授权。
- **[建议]** 出口可用/已占用/宽限保留/切换锁定/待释放/故障/释放失败分别给出可区分状态与时间；“当前IP改变”提示固定IP承诺已受影响。
- **[待接口]** 是否能提供稳定出口标识、IPv4持有保证、端口/网关与出口映射，是独享交付前置能力。不能根据一行LINE绑定就展示“独享已验收”。

**验收**：他客同IP不同端口被拒；同IP从两条线路上报不能分配给不同客户；宽限保留仍参与冲突；前端能区分固定承诺IP与实时线路IP。

## 3. UI-12/UI-13｜备用线路管理与人工主备切换（P0）

### 3.1 入口与服务归属

**建议菜单/入口**：资源管理→“备用线路”查看可用候选及被引用关系；主要业务动作放在**服务详情→资源绑定→故障恢复/主备切换**，避免无服务上下文直接替换线路。

| 页面 | 字段与交互 |
|---|---|
| 备用关系列表 | 服务号、客户、产品类型、主线路/主出口IP、备用线路/目标IPv4、备用状态、归属ROS/CentOS、省市运营商、最后验证时间、被引用次数；搜索服务/线路/状态 |
| 配置备用侧栏 | 只读服务与主出口；按省市/运营商/ROS/在线状态查询候选；候选逐行展示拨号账号掩码、IPv4、HTTP/SOCKS5、健康、排他冲突、是否符合产品要求 |
| 切换任务列表 | 任务号、服务、主/备线路、源/目标IP、发起人/原因、创建及执行时间、实际操作执行方、当前阶段、探测结果、失败/补偿状态 |
| 切换任务详情 | 操作快照、影响服务/访问域名/代理入口、适配器及资源API调用结果、每次尝试与错误码、最终绑定变更、旧占用去向、审计 |

### 3.2 四步受控切换向导

1. **当前绑定**：客户、服务、产品/套餐、固定交付IPv4、目前访问入口、主线路/ROS/状态；展示最近失败检测/切换历史，不以线路最新IP代替合同IP。
2. **选择候选**：默认显示符合地区/运营商及产品能力的健康备用；检查公网IPv4跨客户占用、端口/入口能力、宽限/暂停/终止状态及目标候选时效。需要跨ROS或跨CentOS时**[待接口]**，未确认能力时禁用提交。
3. **影响预览**：对比原/新线路、原/新公网IP、域名/网关/客户交付入口、预计断开重连影响、能否保留固定IP承诺。**人工二次确认并填写原因**，仅有切换权限者可提交。
4. **执行/结果**：生成操作ID与任务，显示“预占→资源接口执行→产品数据面入口重映射→实际探测→确认新绑定→旧占用释放”。失败提供分阶段原因、重试/人工介入，不回填虚假的成功状态。

**[确认]** 当前只设计**人工切换**，不恢复ROS设备级主备、自动切换开关、自动切换频率或定时策略。ROS仍仅拨号；切换中的资源动作由CentOS/资源API与具体产品适配器承担，职责以对外接口能力评审为准。

**[建议]** 如果目标公网IP和原固定IP不同，必须标记“本次会改变客户固定IP”，纳入交付变更记录，并按已确认通知规则告知客户；不能把失败切换当作服务恢复。

**验收**：切换到被他客独享的出口时阻止；成功切换前主绑定仍可查询；失败需展示真实阶段和可恢复任务；无需ROS主备配置界面即可完成业务入口设计。

## 4. UI-21｜服务开通五步向导与预检（P0）

**普通入口**：订单管理→待开通订单；订单列表/订单详情“开通”仅跳向导，不直接执行。仅NEW/PENDING_PROVISION走新购开通，RENEW/EXPAND/CHANGE走变更流程。

| 步骤 | 页面字段与交互 | 校验/业务结果 |
|---|---|---|
| ①订单确认 | 订单号、客户名称/认证、业务负责人、NEW类型、订单状态、预期生效/到期；**订单项子表**含产品、类型、套餐、数量、预计服务实例数、各项快照 | 全部只读，订单项可展开，不允许运营用手工ID覆盖来源 |
| ②交付配置 | 每个订单项选自有或外部代理，按每个服务实例显示分配行；自有短效选池/规则摘要、长效固定出口、独享N个**去重IPv4**候选；外部选可交付反向代理并自动带出采购/供应商 | 五类产品专项能力显示为条件字段；每个外部实例对应不重复的代理配置 |
| ③资源预检 | 产品范围、地区/运营商、配额、固定IP能力、出口跨客户冲突、在线/同步时间、外部归属/上游期限、权限、适配器状态；分项展示通过/阻塞/待确认 | 预检只显示快照，实际提交重验；阻塞项给出原因和资源详情跳转 |
| ④开通确认 | 将生成的服务数、逐实例资源/固定IP/入口、认证方式、期限+**宽限截止**、管理面/真实交付状态预期、操作原因与风险影响 | 高影响操作确认；不产生虚假密钥；真实适配器未接入时不得标识“已实际交付” |
| ⑤开通结果 | 按订单项/实例展示服务编号、实际资源绑定、**固定交付出口IPv4**、当前IP/平台入口、凭证一次性摘要、状态、错误原因、操作ID、后续处理入口 | 成功/失败数量分开展示；部分远端成功/失败保留补偿任务，订单不可错误标记全量成功 |

**[建议]** 直接手工开通作为独立特权入口：从客户详情发起，业务名称选择客户/产品/套餐/周期，走同一资源预检与结果组件；独立权限、操作原因和审计，不作为待开通队列默认表单。

**现有实现差异（GitHub静态核对）**：正式开通页面已采用五步向导，但资源预检和结果页尚未完整呈现真实绑定出口；原型仍缺多实例逐项候选和异常任务样例。不要因此误判旧的技术ID表单是正式业务设计。

## 5. UI-23/UI-24｜服务详情工作区与绑定主子表（P0）

**服务详情是跨模块的统一业务入口**。从客户、订单项、资源、告警、开通结果都应可跳转；可返回原页面。

### 5.1 顶部摘要与核心字段

| 区域 | 详细字段 |
|---|---|
| 业务摘要 | 服务号、客户、客户认证/状态、订单/订单项、产品/套餐（服务时快照）、五类产品类型、交付方式、服务负责人/创建人 |
| 期限与宽限 | 生效时间、业务到期时间、**套餐宽限快照（天）**、**宽限结束时间**、到期剩余、到期后停服原因、当前是否仍占用固定出口 |
| 生命周期 | 业务状态、真实交付阶段、接入可用性、最后成功验证、适配器/上游异常、最近变更/执行任务 |
| 资源摘要 | 自有池或固定线路、**合同固定出口IPv4**与实时当前IP分别显示、HTTP/SOCKS5端口、域名/平台入口、共享/独享模式及占用到期 |
| 外部摘要 | 供应商、采购套餐、上游剩余周期、反向代理配置/平台代理入口、平台代理真实配置/连通状态（上游机密不展示） |
| 认证与额度 | Token/账号/白名单/VPN凭证的类型、掩码与过期、提取/流量/并发/设备权益及实际使用 |

### 5.2 详情必须有的子表

1. **资源绑定**：绑定号、资源类型（POOL/LINE/EXIT_IPV4/REVERSE_PROXY）、对象业务名称、绑定用途/主备、固定交付IP快照、当前IP、有效/保留至、状态、建立/释放时间、变更来源；允许跳线路/池/代理。
2. **出口授权与排他证据**：同IPv4其他共享服务数量、排他状态、所属客户、宽限保留标志、切换预占记录（在有权限时可见）；不泄露其他客户不必要的敏感详情。
3. **备用资源/故障恢复**：备用候选、健康、最后验证、操作“配置备用/人工切换”、任务及探测日志；无支持能力时禁用并标明原因。
4. **凭证与白名单**：掩码、过期、发放/重置、独立权限；非真实下发的凭证不得显示为可用。
5. **生命周期与变更**：订单续费/手工调整、暂停/恢复/终止/宽限停服/回收，记录原状态、目标状态、时间、原因和执行人。
6. **交付执行任务/补偿**：operationId、适配器动作、执行阶段、调用/验证结果、错误与重试、关联订单。
7. **使用和日志/告警**：提取日志、使用统计、API调用、拨号/IP变化、长效专项监控、通知历史，按服务与实际目标过滤。

**[建议]** 顶部业务操作按状态决定是否显示，所有按钮先预检影响，再进入统一业务变更组件。暂停客户调用不等于释放固定出口；到期宽限停服与手工暂停必须能区分。

**现有实现差异**：已存在服务详情子表（绑定、凭证、白名单、变更、释放、长效监控），但宽限、固定/当前IP双快照、备用候选/切换任务、真实交付验证/补偿尚需新增展示与接口。

## 6. UI-25｜服务变更/续费/暂停/恢复/终止（P0）

### 6.1 统一操作组件

- 从**服务详情/服务列表选中一条实际服务**进入，显示服务号、客户、产品、交付入口及当前状态；**不得要求录入“服务ID”**。
- 选择动作后显示该动作的影响项，含凭证、固定IP占用、采购期限、计费/套餐快照（如适用）、受影响域名与监控；任何高风险动作要求二次确认与原因。
- 以**订单为主线**创建续费/扩容/变更；保留有授权的直接调整渠道，使用**相同校验/执行引擎**，必须记录是否来自订单。
- 提交后以业务对象、任务号、实际结果、失败原因和可重试入口展示，不展示原始JSON；异步任务显示执行中状态。

### 6.2 状态/产品差异动作

| 动作 | 表单字段与只读影响摘要 | 最低执行条件 | 完成后的可见反馈 |
|---|---|---|---|
| 续费 | 原到期、续费周期、续费途径（订单/直接）、**新到期/新宽限截止**、采购覆盖期限、凭证/绑定同步 | 客户/产品允许续费；外部上游期限覆盖；确认原固定IP是否仍保留 | 新期限、出口是否原样保留、凭证/网关是否已更新，不能只有svc_instance.expire_at变化 |
| 手工暂停 | 停服原因、即时生效/计划时间、当前绑定/外部入口影响 | 权限通过、真实产品关闭可执行 | 实际停止访问状态、保留占用情况、执行ID；不能仅写SUSPENDED |
| 手工恢复 | 暂停原因、服务未到期/已续费、真实资源/适配器/外部采购校验 | 到期宽限中**不允许靠普通恢复绕过续费** | 恢复结果、代理探测及凭证状态 |
| 到期宽限停服 | 到期时刻、宽限快照、保留出口、自动任务阶段 | 到期时刻到达，立即拒绝访问 | 明确“已停服·保留至X”，待回收/可续费 |
| 人工终止 | 关联订单/客户、待关入口/凭证、是否保留资源（按终止规则）、不可逆影响 | 高危二次确认，真实关闭后才承诺资源释放 | 终止/关闭/解绑/释放各步骤状态及记录 |
| 指定资源变更 | 旧线路/旧出口、新候选、排他冲突、访问入口/域名变化 | 独享冲突检查、数据面与资源API能力确认 | 切换/资源绑定历史；固定IP变化须提示 |
| 更改外部代理 | 旧/新采购与平台代理、客户与期限、适配状态 | 新入口真实可用/采购覆盖，旧入口关闭/解绑策略明确 | 新入口、历史代理、补偿与验证结果 |

### 6.3 重点阻断及竞品参考

- 独享IP的续费、暂停及宽限保留期间仍保持公网IPv4排他，不因客户不可访问自动允许他客占用。
- 原服务宽限已结束且资源被释放时，不得显示“保证恢复原IP”；只能进入新资源再分配/业务异常处理分支。
- 竞品有客户套餐“延时”等直接动作，但该交互只作为**特权直接调整**参考，不能绕过订单主路径和审计。
- 当前`ServiceChangeView.vue`仍为服务ID输入和JSON结果，需要后续第三轮原型、开发整改。

### 8.3 必须同步显示的风险

1. **采购客户、代理客户、服务客户**及授权范围是否一致；客户专属采购不可交叉绑定其他客户。
2. 上游期限是否覆盖平台服务新期限；外部采购快到期时显示风险/引导续购，不能静默自动完成服务续费。
3. 上游启用不代表平台代理已配置，平台状态与真实探测分开；正在执行中不可重复发起不可幂等操作。
4. 敏感Token/密码/供应商URL参数默认掩码，不能将上游密钥复制到客户交付凭证。
5. 客户服务终止后的代理解绑不等于供应商采购取消；采购应独立留存以供后续授权使用。
