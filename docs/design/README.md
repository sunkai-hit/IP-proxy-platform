## 设计依据与适用范围

- [正式V1.2需求说明书](../requirements/IP代理管理平台需求说明书-V1.2.docx)：仍是当前已发布的需求基线。
- [彩虹竞品调研报告](../research/competitors/caihong-2026-10-14/report.md)：竞品页面观察和既有实现差异分析。
- [调研后的业务确认](../research/competitors/caihong-2026-10-14/business-confirmations.md)：用户最终业务约定优先于报告中的早期推测。

**已批准的第二轮前置原则**：①独享按公网出口IPv4跨客户排他；②长效/独享分别按套餐配置宽限天数；③只设计人工主备切换。

**仍需评审的边界**：宽限默认/是否允许0、同客户独享IP复用/计数、固定IP的真实保障能力、备用跨ROS执行接口、外部采购多客户授权、数据面幂等补偿。设计稿中的API路径、数据列名、任务状态均为待技术确认方案，不应直接当作现有实现。

## 约束

- 本轮没有更改正式Word、交互原型、数据库迁移或业务后端。
- 不采纳竞品的充值、彩虹币、卡密、云手机、内容管理、人工实名认证二审或新一套内部运维告警。
- 保留自有来源型资源池、CentOS↔ROS当前1:1、ROS仅拨号、节点=家宽/线路、供应商采购+反向代理交付链。
- 外部真实数据面未确认前，不允许将管理面逻辑开通说成已经真实可用。
