## 2. UI-02–05 客户管理（§5；E10/E11/E41–E44）

### 2.1 客户列表 / 详情

- **查询**：编号、名称、联系人、个人/企业类型、认证状态、客户状态、业务负责人、是否有有效服务；按权限处理手机号/邮箱敏感查询。
- **列表**：客户编号/名称、类型、认证状态、状态、联系人（可掩码）、当前服务数、即将到期服务数、**宽限停服服务数**、最近到期日期、业务负责人、更新时间；不增加余额/充值字段。
- **详情页分区**：基本资料；认证历史；账号与鉴权；**服务实例子表**（服务号、产品/套餐、有效期/宽限、真实交付及绑定IP摘要）；订单子表；使用统计；长效告警/机器人引用。只有实际存在的来源数据才展示。
- **操作**：查看客户详情、启停与引用保护、发起新购订单、**受控直接开通**、从服务行进入续费/暂停/人工切换（有权限才显示）。不得给客户详情添加“直接绑定家宽/线路”。
- **现有前端**：`CustomerDetailView`已包含认证/账号/服务/凭证摘要，本轮重点追加宽限、资源绑定入口、服务操作及任务引用，而不是重新建另一份客户服务主表。

### 2.2 认证和客户账号

| 对象 | 字段 | 交互/控制 |
|---|---|---|
| 认证 | 申请编号、个人/企业、材料摘要、申请时间、初次审核状态、审核人/时间、拒绝原因、历史 | 可查看、审核、驳回、重新提交；不新增竞品“实名认证成功后人工二次复核” |
| 客户账号 | 账号、所属客户、账号类型、状态、认证方式、最后使用/登录、白名单数与绑定服务数 | 新增/冻结/停用、重置认证（需要权限）；冻结客户/账号与服务使用规则联动 |
| 服务认证 | 服务号、Token/白名单/账号/密钥类型、掩码、创建/到期、最后使用、状态 | 真正新生成凭证仅受控一次显示；供应商密钥、客户Webhook Secret不出列表；日志不含明文 |
| 使用概览 | 提取数、实际流量、统计时段、数据来源、最后更新时间 | 数据面未回传不得以“提取量”充当真实流量 |

## 3. UI-06–10 自有资源：列表与主子表（§6.1–6.5；E02–E05/E16–E21）

### 3.1 CentOS和ROS

| 资源页 | 列表字段与筛选 | 详情、操作和禁止事项 |
|---|---|---|
| CentOS | 主机名、账号、管理IP、位置、运营商、状态、CPU/内存/负载/磁盘、**B段/C段**、线路数量、心跳/数据时间；按状态/地区/名称/IP筛选 | 详情关联对应ROS（当前1:1）、下属线路/当前IP统计/监控/远程操作/日志；B/C按对应ROS下线路当前有效IPv4聚合、只读；确认真实CentOS能力再开放远程 |
| ROS | ROS ID、记录名、状态、CPU/内存/负载/磁盘、线路数/在线数、当前拨号IP数、BAS数、开机时长、上报时间 | 详情含所属线路、BAS汇总、上报/拨号日志；无冗余所属CentOS列表列；**不得出现B/C段、主备切换、替换ROS、自动切换** |
| 关联 | CentOS/ROS相互可导航，ROS→线路列表筛选 | 当前1:1不变；“主备线路人工切换”只发生在**具体客户服务和线路出口**业务上下文 |

### 3.2 家宽/线路：统一节点与ROS逻辑线路

**查询条件（继承Word§6.4）**：所属ROS、所属CentOS、管理/域名绑定状态、在线/异常、域名、当前IP、共享/长效类型、账号前缀、拨号账号、省市、运营商、VPN能力、BAS。  
**列表列**：线路ID/别名、ROS/对应CentOS、拨号账号（按权限脱敏）、当前IP、HTTP/SOCKS5、绑定域名、共享/长效、省市运营商、在线/管理状态、用户上限/当前在用、VPN支持、BAS、最近拨号/ROS上报/最近IP变化。  
**详情主区**：稳定来源ID（如接口可给）、拨号账号与认证掩码、当前IP与上报时间、HTTP/SOCKS5端口、域名、BAS/BRAS/PPPoE Server、延迟、拨号/重启间隔、管理状态；不以动态IP做主键。  
**必须存在的子表**：
1. **资源池成员关系**：所属来源池、加入时间、共享/长效线路类型、是否启用；一线路可在多个池；
2. **服务资源引用**：服务号、产品、绑定方式、**客户名称通过服务引用读取**、固定出口IP快照、是否备用、业务期限/宽限、切换任务；
3. **拨号/IP变化历史**：原/新IP、触发来源、拨号结果/BAS变化、时间及同步ID；
4. **域名/远程操作日志**：变更与同步结果；只调用真实支持的接口。

**操作**：编辑可编辑的管理属性、设置共享/长效类型、绑定域名、设为管理、健康/延迟检测、远程管理（通过CentOS），查看拨号/IP日志，以及**从关联服务进入人工备用切换**；不能在资源列表直接把线路分配给客户。

**稳定标识**：[用户确认] “所属ROS+拨号账号”可作为业务关联线索，但未确认天然唯一；同账号多条记录或多拨会话，交资源API联调验证来源ID/去重策略；不得擅自加组合唯一索引。

### 3.3 来源型资源池

| 层级 | 字段或操作 |
|---|---|
| 查询/列表 | 池编号/名称、省市运营商、状态、成员总数、SHARED数量、LONG数量、在线/异常线路、当前IP数、当前去重IP数、B/C段、规则版本/统计时间 |
| 池详情 | 来源属性、成员与汇总、**成员线路主子表**、实际服务使用引用、成员变更历史；支持按ROS/类型/状态/地区筛选候选 |
| 成员维护 | 批量加入/移出、显示资格检查和将影响的服务/规则；停用池只影响新选择，不删除历史绑定 |
| 口径 | 成员可N:M重叠；SHARED/LONG为线路归类，不把五类产品直接变成池类别；跨池汇总按线路/IPv4真实口径去重 |

## 4. UI-14 域名配置与变化（§6.7；E18/E19）

- **列表/查询**：域名、当前解析/目标IP、线路、关联服务（通过绑定）、状态、DNSPOD最后同步结果及时间、客户（由服务归属派生）；可筛选失配/同步失败。
- **详情**：域名记录、绑定线路、当前线路IP与DNS记录IP对比、关联服务/外部入口、解析历史、异常/切换任务。
- **操作**：绑定/解绑实际线路、测试DNS、**预览同步内容**、提交真实DNS同步、查看日志/重试；切换备用线路可能改变绑定IP，必须在影响预览中提示。
- **约束**：不能因为接口未响应就写“已同步”；敏感DNS密钥在后台掩码。竞品能看到DNSPOD同步入口（E18）不等于已验证该写操作。

## 5. UI-15–17 外部资源的非P0列表与跳转（§6.8–6.10；E09/E30–E32）

- **供应商列表**：编号/名称、联系人、支持的五类产品能力、API/管理地址摘要、状态、最后测试结果、采购数、关联服务数；不直接显示上游密码。详情主子关系**供应商→采购套餐→反向代理→服务**。
- **采购/代理**完整P0字段和停用影响见[核心业务详规§8](V1.2-P1-第二轮-核心业务页面字段及交互详规.md)；这里强调列表必须可以按供应商/采购/客户/服务导航，禁用采购或代理前列出下游有效服务的影响列表。
- **客户访问入口与上游地址严格分区**。竞品可能有源网址/认证/网关字段，但只映射到正确对象，不在客户页面展示供应商原始Secret。
- **外部使用记录**：客户、产品、对应代理、调用时间、调用结果/流量（如真实数据面提供）、状态与错误；不得把“外部产品使用”直接等同于平台提取日志。

## 6. UI-18 产品体系及专项参数（§7.1–7.7；E06–E08/E24/E30）

| 五类产品 | 产品专项表单/详情字段 | 不可混淆的业务语义 |
|---|---|---|

| 长效IP | 固定出口承诺、周期/更换次数、共享出口允许度、专项监控/通知支持、地区运营商 | 长期固定IP但可跨客户共享，不能意外切换IP而不记业务变更 |
| 独享IP | 独享去重IPv4数量、跨客户排他约束、固定IP承诺、更换次数/时效与故障恢复、范围 | 不要求独占底层带宽；数据面必须提供真实独享保证 |
| VPN | 协议、凭证类型、设备/连接数、出口能力、真实适配器状态 | VPN产品组负责数据面，不创建VPN资源池 |
| 隧道 | 平台接入域名/IP、端口、协议、认证、会话保持、并发/入口状态 | 固定接入入口与出口IP并非同一个概念，入口和出口字段要分区 |

- **公共配置**：产品编号/名称、类型、接入方式、协议、认证、地域/运营商、产品说明、状态、代码内置规则版本（只读）；产品启用前确认套餐与适配器能力。
- **套餐子表**：显示套餐编号/名称、时长、额度、价格、启用状态、**宽限天数（长效和独享独立）**，每项可跳套餐详情。
- **禁止**：把竞品负数“套餐”当正常销售；负额度/减配通过受控变更，不支持普通套餐负资源数量。秒/分钟/天、元/Byte需明示单位。
- **静态代码差异**：当前产品详情含“故障自动替换”等历史专项字段，本轮已确认只有**人工主备切换**，设计中禁用旧自动切换运营入口；是否保留字段供代码内部使用应由技术负责人评审，不盲删迁移。

## 7. UI-27/28 基础监控与 UI-30–32 专项客户告警（§9/§11；E02–E05/E22/E27/E34）

### 7.1 CentOS与ROS监控

| 监控页 | 展示指标 | 操作 |
|---|---|---|
| CentOS监控 | 在线/心跳、CPU、内存、系统负载、硬盘、管理IP、**B/C段**、同步采集时间、异常原因 | 筛选、趋势、跳主机详情/关联线路/对应ROS，限权延迟检测 |
| ROS监控 | 运行状态、CPU/内存/负载/硬盘、在线线路数/总数、当前拨号IP数、BAS汇总、拨号/上报时间 | 跳ROS/线路/BAS及拨号日志；**无主备开关、B/C段** |
| 进程运行观测 | 竞品E27曾显示进程/端口/运行时间 | 暂只作为未来可选的应用运维指标，不扩建现行ROS监控范围 |

**数据有效性**：表头/指标必须标采样时间；超时或缺失为UNKNOWN，不能沿用旧的ONLINE绿灯。

### 7.2 客户专项长效代理监控

- **监控配置**：监控号、客户/服务引用、真实代理地址、端口协议、检测类型（TCP/代理请求/HTTP）、周期、超时、连续失败阈值、正常/异常/未知、最后检测/成功/异常、通知机器人、是否发恢复通知、启用状态。
- **检测对象/分组交互**：可借鉴竞品E34“增加分组”的效率，在监控详情中选择客户拥有的多个服务/代理目标，并可增删候选；**不按ROS主机直接给不相关客户发内部资源故障通知**。
- **客户机器人**：所属客户、钉钉/飞书、Webhook掩码、测试发送、最后结果、引用该机器人的监控配置；跨客户选择必须禁止。
- **告警/通知**：告警号、服务/客户、目标、首发/最新异常、当前失败次数、TRIGGERED/RECOVERED/CLOSED，通知发送/重试/HTTP状态；人工归档不等于探测恢复。
- **故障切换影响**：成功切换后必须同步更新所监控的**实际代理目标**，记录原/新目标；告警是否恢复由下一次真实探测决定，不因“切换成功”自动清除告警。

| 10.9 域名变更日志 | 域名、原/新解析、服务/线路引用、DNS同步结果、时间 | 点击恢复/切换任务，失败提供受控重试 |
| 10.10 外部供应商与反向代理日志 | 供应商/采购/代理、应用/测试/禁用、真实回执、错误、时间 | 关联客户服务及异步补偿任务；不保存上游Secret |
| 10.11 操作日志 | 操作人、角色、对象、变更前后（脱敏）、原因、IP/时间/结果 | 包括宽限、人工主备切换、独享排他、强制回收等高风险动作 |

**建议补充两个跨现有日志的筛选维度**：服务号与`operationId`。不要简单再新增第12类重复日志模块；切换/交付任务可作为服务详情和操作日志的业务筛选视图。

**可用性要求**：行点开“详情”或关联业务时携带原筛选条件；长JSON或技术堆栈默认收起并进行敏感字段过滤；每个日志明确数据来源/保留策略、成功/失败及重试次数。

| 12.2 ROS资源统计 | ROS、在线数/上报、线路数/在线线路、当前拨号IP数、BAS | 无B/C段、主备状态；统计时间与最后上报时间 |
| 12.3 家宽/线路统计 | 地区/运营商、类型SHARED/LONG、在线/故障、当前IP数、重拨/IP变化 | 统计线路数、在线会话数、去重IPv4、历史变化次数分别定义 |
| 12.4 资源池统计 | 来源池、省市/运营商、成员共享/长效/在线/异常、当前/去重IP、B/C段 | 同线多池允许，跨池汇总去重，不简单求和 |
| 12.5 客户使用统计 | 客户、服务、产品、周期、提取量、真实流量、配额/已用 | 未接入产品数据面时真实流量显示“暂无数据/未接入”，不填0或冒用提取量 |
| 12.6 产品与服务统计 | 五类产品、套餐、有效/暂停/到期、交付阶段、续费、终止 | 建议拆分“可访问ACTIVE”和“宽限停服保留”“管理面已开通待验真” |
| 12.7 外部采购与反向代理统计 | 供应商、采购、反向代理、到期/续购、有效服务、代理适配/连接状态 | 展示采购不足覆盖下游服务的风险，采购/代理/服务数量分开 |

**指标字典与用户提示**：
- 当前公网IP数 = 截至统计时有效上报的线路IP数；当前去重IPv4数 = 当前线路IP按真实IPv4去重，非历史累计。
- “B段/C段”按现行需求暂以/16、/24前缀去重，**前缀业务叫法仍需用真实样例向资源API组复核**；不擅自改成其他网络定义。
- IP提取量 = API实际返回的IP数量，**不是**连接数、使用流量或可用库存。
- 独享出口数 = 去重且已授权的IPv4数量，保留宽限/切换预占与实际ACTIVE业务使用分别统计。
- 新增宽限保留与待回收统计时带时间点与来源，防止把“仍被占用”和“仍可访问”混淆。

## 13. 第二轮设计审核与第三轮移交

- **业务评审优先**：本轮已经确认的“三原则”直接作为设计约束；宽限默认天数、同客户多独享服务复用策略、采购多客户复用、备用跨ROS能力与资源API稳定ID仍须专项确认，**不在页面稿中静默定案**。
- **技术评审优先**：出口排他加锁对象与幂等策略、状态字段和事件表、数据面适配器接口、跨系统失败补偿。UI上“可点击”不得先于真实接口承诺。
- **原型验收优先**：至少覆盖“多订单项/多实例交付、独享IPv4冲突、宽限停服后续费恢复、人工切换成功/失败、外部采购到期、服务变更、真实交付状态”七组交互场景。
- **三轮统一发布**：经评审后才合并正式Word章节、资源/生命周期图、原型和API契约，逐项创建研发Issue；本轮文档没有修改正式基线或业务代码。
