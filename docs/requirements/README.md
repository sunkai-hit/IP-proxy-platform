- **代码：** 后端、前端、五类产品业务及统一授权、订单与服务流程。
- **数据库：** 既有Flyway V1～V27及实际实体/SQL映射；已执行的历史迁移不改写，确需升级时新增迁移。
- **接口：** 以接口说明书V1.0核对现有API和两组边界；尚未获得的产品组真实接口不得标为已联通。
- **原型：** `prototype/`为模拟交互资料，不等于正式前端或真实业务数据；按V1.3逐项核对已确认流程。
- **验收：** CI模拟、PostgreSQL联测、真实设备侧联调三种证据分别记录；不把模拟结果冒充真实代理交付。

**原则：不扩张、不反复扣个别细节；优先形成V1.3统一可审查研发版本。**
