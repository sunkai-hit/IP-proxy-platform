## 正式需求适用范围

1. 客户、产品/套餐、订单与服务实例，五类产品（短效IP、长效IP、独享IP、VPN、隧道）的管理面。
2. 自有资源模型：当前阶段 CentOS↔ROS 1:1；ROS承担拨号；CentOS承担其他管理动作和B/C段统计；家宽/线路（节点）及当前公网IP为资源属性；资源池按来源属性组织线路。
3. 外部交付：供应商→采购套餐→反向代理配置→客户服务；不默认纳入自有资源池。
4. 订单驱动的服务开通闭环：新购订单→确认→逐项交付配置→资源预检→创建服务实例→资源绑定/认证→交付结果；续费、扩容、变更走服务变更流程。
5. 监控、日志、数据统计、长效代理专项监控/告警、系统权限与审计。
