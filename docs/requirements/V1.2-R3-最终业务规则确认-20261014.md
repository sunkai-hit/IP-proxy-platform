# V1.2-R3 最终业务规则确认

2026-10-14，用户确认 C01—C08 与宽限时间口径。

- C01：同一客户的多个服务可有条件共用采购套餐；仅在供应商允许、可验证容量及无超额风险时开放；跨客户不可复用。
- C02：外部采购成本、额度和剩余额度**可以记录，但不是必填字段，也不触发后续业务或扣减逻辑**。
- C03：上游采购到期提前提醒，到期停服；平台保留停用配置但不承诺上游资源保留。
- C04：**先确认客户已付款，才进行可能产生费用的外部采购或续购**。付款失败、未知或待处理不应安排新采购；订单确认不等于付款成功。供应商采购仍由运营人员在供应商侧完成，本版不增加自动采购/充值模块。购买后确认上游期限和可用性，才完成真实交付或恢复。
- C05：一个客户可配置多个机器人，不同长效服务可选择不同钉钉/飞书机器人。
- C06：人工暂停不会自动延长套餐有效期。
- C07：主动提前终止不享有宽限保留；须真实关闭与释放成功。
- C08：备用优先同地区同运营商；跨地区/运营商或改变固定出口须客户事先同意及接口能力验证。
- T01：宽限期按原到期时刻加 N×24 小时计算，0天到期立即停服并进入受控回收。

## C04 安全顺序

客户提交新购/续费订单 → 确认真实付款成功 → 验证是否有足够已购上游能力 → 若不足由运营向供应商采购或续购 → 确认上游采购生效且覆盖目标有效期 → 平台代理真实下发/核验 → 客户服务开通或恢复。

付款状态未知与采购尚未生效时不可宣称真实交付。内部授权直接调整应保留独立权限、原因和审计，不得冒充客户已付款。

该规则需要同步正式Word、36页面原型、数据库、API、代码和验收；真实联调仍依赖外部两组的接口与环境。
