# IP代理管理平台 · 完整交互原型

基于《IP代理管理平台需求说明书（详细需求版 V1.0）》整理的纯前端后台原型。当前版本已从“基础列表页”扩展为“列表 + 二级页面 + 典型业务动作”的完整演示版本。

## 原型定位

- 用于需求评审、产品演示、页面结构确认和研发理解。
- 不连接真实后端，不执行真实的资源同步、拨号、代理、订单、服务开通、监控或告警动作。
- 所有数据均为模拟数据，新增、编辑、审批、释放等操作以弹窗、抽屉、向导和提示方式演示。
- 风格参考阿里云控制台：深色侧边导航、浅色工作区、蓝色主操作、橙色强调、高密度表格。

## 一级页面

- 首页工作台
- 客户管理
- 资源管理
- 产品管理
- 订单与服务管理
- 监控中心
- 日志中心
- 告警中心
- 数据统计
- 系统管理

## 已补全的二级页面与交互

### 客户管理
- 新增客户、编辑客户、客户详情
- 客户服务与认证信息查看
- 认证审批列表、认证详情、审批通过/驳回
- 从客户列表直接发起服务开通

### 资源管理
- CentOS、ROS、家宽/线路、IP资源详情
- IP资源池新增、编辑、详情
- 独享资源详情与释放确认
- 外部供应商新增、编辑、详情、接口测试
- 外部资源接入配置、接入任务详情与同步演示

### 产品管理
- 产品新增、编辑、复制、详情
- 五类产品基础与专项配置字段
- 套餐新增、编辑、复制、详情
- 产品资源策略新增、编辑、详情与资源验证

### 订单与服务
- 创建订单、编辑订单、订单详情
- 服务开通向导
- 服务实例详情
- 服务变更、续费、暂停/恢复演示
- 到期与资源回收确认

### 运维能力
- 各层级监控详情与历史趋势
- 日志详情
- 告警详情、确认和处理
- 告警规则新增、编辑、测试
- 钉钉机器人配置与测试演示

### 系统管理
- 用户新增、编辑、详情、重置密码演示
- 角色新增、权限编辑、详情
- 参数新增、编辑
- 登录日志和操作审计查看

## 运行方式

本项目无构建依赖，可直接打开 `index.html`。

推荐启动本地静态服务器：

```bash
python -m http.server 8080
```

浏览器访问：

```text
http://localhost:8080
```
