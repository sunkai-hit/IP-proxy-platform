# IP代理管理平台 · 原型演示

基于《IP代理管理平台需求说明书（详细需求版 V1.0）》整理的纯前端后台原型。

## 目标

- 仅用于需求讨论、产品原型演示和页面结构确认。
- 不连接真实后端，不实现真实的资源同步、拨号、代理、订单、监控或告警能力。
- 所有展示数据均为模拟数据。
- 风格参考阿里云控制台：浅色内容区、蓝色主操作色、橙色品牌强调、高密度表格和后台导航结构。

## 已覆盖页面

- 首页工作台
- 客户管理
- 资源管理
  - 资源概览
  - CentOS列表
  - ROS列表
  - 家宽/线路列表
  - IP资源列表
  - IP资源池
  - 外部供应商
- 产品管理
- 订单与服务管理
- 监控中心
- 日志中心
- 告警中心
- 数据统计
- 系统管理

页面中包含 Tab、筛选、详情抽屉、状态标签、模拟监控指标等原型交互。

## 运行方式

本项目无构建依赖，直接打开 `index.html` 即可演示。

也可以启动任意静态文件服务器：

```bash
python -m http.server 8080
```

然后浏览器访问：

```text
http://localhost:8080
```
